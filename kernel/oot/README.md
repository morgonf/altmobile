# Сборка модулей голосового тракта вне дерева ядра

Собирается прямо на телефоне, там есть и дерево сборки ядра, и компилятор.
Пересобирать надо все пять модулей сразу, потому что патч `0002` добавляет поля
в `struct q6voice_session`, а её размер приходит из `q6voice-common`.

Что нужно:

1. Взять пять исходников и их заголовки из дерева ядра ALT, каталог
   `sound/soc/qcom/qdsp6`: `q6voice.c`, `q6voice-common.c`, `q6mvm.c`,
   `q6cvp.c`, `q6cvs.c`, `q6voice.h`, `q6voice-common.h`, `q6mvm.h`, `q6cvp.h`,
   `q6cvs.h`.
2. Наложить патчи `0001`..`0004` из каталога выше.
3. Положить рядом `Makefile` и `q6afe.h` из этого каталога. Заголовок это
   заглушка: из настоящего `q6afe.h` нужна одна функция, а сам он лежит в
   дереве ядра, которого на телефоне нет.
4. Собрать.

```
make
```

Проверено на телефоне 26 сентября 2026, ядро
`7.1.0-qualcomm-sdm845-alt0.rc1`. Собирается без предупреждений. Компилятор на
телефоне новее того, которым собрано ядро (15.3.1 против 15.2.1), сборка об
этом предупреждает, на загрузку модулей это не влияет благодаря контрольным
суммам символов.

Загружать надо тоже все пять сразу, иначе старый `q6voice-common` выделит
структуру сессии прежнего размера, а новый код полезет за её границу.
