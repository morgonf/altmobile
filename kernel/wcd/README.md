# Ограничение шкалы громкости разговорного динамика

Драйвер кодека WCD9340 задаёт элементу `RX0 Digital Volume` шкалу от минус 84 до
плюс 40 дБ. Верхние сорок положений это цифровое усиление выше единицы, на них
сигнал обрезается, и заодно перестаёт работать эхоподавитель. Патч
`0001-wcd934x-cap-rx0-volume-at-0db.patch` срезает эту часть шкалы.

Собирается на самом телефоне, вне дерева ядра.

1. Взять `sound/soc/codecs/wcd934x.c` из апстрима той же версии ядра. Для
   `7.1.0-qualcomm-sdm845-alt0.rc1` это тег `v7.1` дерева Торвальдса. Сверено:
   определения элементов совпадают с тем, что сообщает устройство, до последней
   цифры, включая `max=124` и шкалу минус 84 дБ с шагом 1 дБ.
2. Наложить патч.
3. Положить рядом три заголовка из этого каталога, `wcd-clsh-v2.h`,
   `wcd-common.h`, `wcd-mbhc-v2.h`, они тоже из `sound/soc/codecs/`. Заголовки
   регистров (`linux/mfd/wcd934x/*`) брать не надо, они есть в дереве сборки на
   телефоне.
4. Собрать с `Makefile` из этого каталога.

```
make
```

Установка и откат скриптами `scripts/wcdinstall.sh` и `scripts/wcdrevert.sh`,
после каждого нужна перезагрузка. Заводской модуль сохраняется рядом с суффиксом
`.orig`.

Проверено 26 сентября 2026: после установки `RX0 Digital Volume` и
`RX0 Mix Digital Volume` получают `max=84`, звуковая карта поднимается, все
зависимые модули загружаются.

Оговорка: если ALT наложил на этот файл свои правки, наш модуль их затрёт.
Признаков таких правок нет, но проверить это можно только по исходному пакету
ALT, а его в репозитории для этого ядра не оказалось.
