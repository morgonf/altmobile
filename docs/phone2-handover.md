# Второй телефон («Прототип 2») в подарок

Цель (11.10.2026): повседневный телефон, удобный в использовании.
Получатель разбирается в Linux (терминал и root не прячем), оператор МТС,
удалённый доступ по ssh пока оставляем. Как телефон ставился: память
`oneplus6t-second-phone`, `docs/install.md`.

Обозначения: ✅ проверено, ⚠️ работает с оговорками, ❌ не работает,
⬜ не проверено.
