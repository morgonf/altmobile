   Firefox.

   Правильно: выключить 802.11r на роутере, либо научить NetworkManager

   заставка plymouth вместо текста. Замечено пользователем 27.09.
4. Устойчивость к обновлениям: пересобранные модули лежат поверх файлов

## Как снимать экран и проверять

Снимок: `spectacle -b -n -f -o файл` (весь экран) или `-a` (активное окно)
в окружении сеанса, окружение брать из `/proc/$(pgrep -x plasmashell)/environ`.
Отдельный модуль: `plasma-settings -s -m kcm_имя`. Готовый скрипт
`~/shots2.sh kcm_имя...` кладёт снимки в `/tmp/.private/altlinux/sh_*.png`.
Внимание: `pkill -f` с шаблоном, который есть в собственной командной
строке, убивает свою же ssh-оболочку, писать `[g]db`.

## Публикация на GitHub

Публичная копия лежит в https://github.com/morgonf/altmobile (ветка `main`).
Её не правят руками, а каждый раз заново выгружают из этого репозитория
скриптом `scripts/export-public.sh КАТАЛОГ`. Скрипт вырезает калибровку
ACDB и обезличивает сетевые данные по неотслеживаемому
`scripts/export-private.sed`. Переписывание детерминировано, старые коммиты
получают те же хеши, поэтому новая выгрузка отправляется обычным push
(`git push origin master:main`, ключ `~/.ssh/id_ed25519_nout`).
