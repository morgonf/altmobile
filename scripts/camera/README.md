# Проверка камеры на телефоне

Скрипты кладутся в домашний каталог `altlinux` на телефоне и запускаются
по ssh.

- `ctrun.sh "сценарий"` запускает «Камеру» в окружении сеанса Plasma и
  выполняет сценарий `camtest.py`, например
  `ctrun.sh "wait 10; tap 750 1860; wait 8; tap 690 720; wait 5; tap 540 1860; wait 8"`
  (переключить на IMX519, коснуться для фокуса, снять). Журнал libcamera
  с отладкой автофокуса и экспозиции пишется в
  `/tmp/.private/altlinux/pc-test.log`. Приложение умирает вместе с
  ssh-сессией, поэтому весь сценарий идёт одним запуском.
- `tap.py X Y [удержание]` касается экрана через виртуальное устройство
  uinput. Нужен доступ к `/dev/uinput`, до перезагрузки он даётся так:
  `setfacl -m u:altlinux:rw /dev/uinput` от root.
- `lenspoll.sh СЕКУНДЫ [subdev]` раз в 50 мс читает положение линзы
  (`focus_absolute`). У IMX519 мотор на `v4l-subdev20`, у IMX376 на
  `v4l-subdev23`, номера сверять по `/sys/class/video4linux/*/name`.
- `fpsmeas.sh ШИРИНА ВЫСОТА VBLANK...` настраивает тракт IMX519 через
  `media-ctl` и меряет длительность кадра по меткам времени буферов
  V4L2 при каждом VBLANK. По двум VBLANK получается настоящая длительность
  строки. «Камера» и `cam` при этом должны быть закрыты.

Координаты для 1080x2340 при масштабе 3: спуск (540, 1860), переключение
камеры (750, 1860).

Ловушка. `cam -s width=2328,height=1748` выбирает у IMX519 режим
3840x2160, а не режим видоискателя «Камеры». Режим датчика смотреть в
журнале (`Line duration ... at WxH`) или через `media-ctl -p`.
