
## Экран блокировки только с PIN (11.10.2026, alt1.mobile6)

`plasma-mobile-lockscreen-pin-only.patch`. Upstream при любом нажатии
аппаратной клавиши переводил экран блокировки в «режим клавиатуры»
(открывал системную клавиатуру поверх цифровой панели) и дописывал
`event.text` в пароль, а в поле PIN был значок переключения на клавиатуру.
У пользователя PIN: кнопка питания при пробуждении открывала клавиатуру с
русской раскладкой, а лишние нажатия (buffyboard от ttyescape) попадали в
PIN. Теперь значок скрыт, касание поля клавиатуру не открывает, от
аппаратной клавиатуры принимаются только цифры, Backspace и Enter.
Проверено пользователем на обоих телефонах.
