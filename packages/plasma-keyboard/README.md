# plasma-keyboard 6.7.5

Экранная клавиатура Plasma Mobile (на Qt Virtual Keyboard). Что мешало
на телефоне и что сделано 28.09.2026 (проверено пользователем):

- **Языки не выбраны.** Модуль «Экранная клавиатура» помечен только для
  ПК (нет `X-KDE-FormFactors` с `handset`), и «Параметры» на телефоне его
  не показывают, выбрать языки негде. Без списка клавиатура берёт
  системную раскладку. Список задаёт `system/plasma/keyboard.sh`
  (`plasmakeyboardrc [General] enabledLocales=ru_RU,en_US`). Сам модуль
  открывается `kcmshell6 kcm_plasmakeyboard`, но вёрстка у него для ПК.
- **Кнопка языка открывала меню** вместо переключения на следующий
  язык: в стиле Breeze `languagePopupListEnabled: true`. `install.sh`
  выключает это свойство.

Вибрация нажатий оставлена выключенной, так хочет пользователь.
Отчёт в KDE: модулю не хватает формфактора handset, меню языков при двух
языках лишнее.
