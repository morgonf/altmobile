# plasma-camera 2.1.1: камера для OnePlus 6T

Приложение камеры KDE для телефонов, работает с libcamera напрямую.
Вместе с libcamera из `packages/libcamera` (автофокус, фокус по клеткам
кадра, замер экспозиции по месту) даёт камеру в духе Google Камеры.

Патч `plasma-camera-2.1.1-alt-mobile.patch` (5 коммитов поверх тега v2.1.1):

1. **Видоискатель не шире 2400 точек.** По умолчанию бралась полная
   матрица 16 Мп, программный ISP давал на ней 11 кадров/с, а фото
   снимаются из того же потока. Режим 2328x1748 (биннинг 2x2 у IMX519):
   22 кадра/с и меньше шума в темноте, фото 4 Мп.
2. **Фокус по касанию.** Касание в видоискателе наводит фокус и
   экспозицию на это место (`AfMetering=Windows`, `AfWindows` в
   координатах матрицы с учётом поворота и отражения кадра,
   `AfTrigger=Start`); кольцо фокуса белое при поиске, цвета акцента при
   удаче, красное при неудаче; рядом ползунок поправки экспозиции
   (`ExposureValue`, -2..+2 EV). Долгое нажатие: фиксация фокуса и
   экспозиции (`AfMode=Auto`, `AeEnable=false`) с надписью. Через 8 с
   без фиксации камера возвращается к непрерывному фокусу по центру;
   касание мимо кольца снимает фиксацию. Состояние фокуса берётся из
   метаданных кадров (`AfState`).
3. Кольцо белое, пока не начался новый поиск.
4. Затвор ждёт конца поиска фокуса (не больше 1,5 с), как в Google
   Камере: раньше снимок во время поиска выходил размытым.
5. Видоискатель: половина полного размера (2320x1748, режим с
   биннингом), а не «стандартный» 2048x1536, который программный ISP
   вырезал бы из середины кадра. Делится пополам только матрица шире
   3200 точек (основная IMX519). IMX376K (2584x1940) остаётся в полном
   размере, потому что на половине (1288x970) программный ISP не может
   начать дебайеризацию и приложение закрывалось.

`plasma-camera.ru-add.po`: 25 непереведённых строк версии 2.1.1 (каталог в
пакете ALT старше программы) и строка фиксации фокуса. `mo-merge.py`
добавляет их в готовый `.mo` без gettext.

Установка: собрать на телефоне (`cmake -B build -DCMAKE_INSTALL_PREFIX=/usr
-DKDE_INSTALL_LIBDIR=lib64 -DCMAKE_BUILD_TYPE=Release`, нужны
libcamera-devel, libexiv2-devel, libinih-devel), затем `install.sh` от
root. Snapshot (камера GNOME) спрятан из меню: через PipeWire он открывает
камеры параллельно, а на 6T они работают только по одной.
