# ALT Mobile на OnePlus 6T: звук в голосовых вызовах

Материалы работы над голосовым трактом OnePlus 6T (fajita, sdm845) под ALT Mobile,
ядро `7.1.0-qualcomm-sdm845-alt0.rc1`.

## Что уже решено

**Эхо у собеседника и отсутствие шумоподавления.** Причина не в калибровке и не в
громкостях, а в одном отсутствующем свойстве дерева устройств. Драйвер `q6voice`
умеет две последовательности настройки обработки голоса, полную и урезанную, и
выбирает её по свойству `qcom,cvd-v2.3` узла `q6voice-dais`. Без свойства
топология создаётся, но не применяется: команда `VSS_IVOCPROC_CMD_TOPOLOGY_COMMIT`
(`0x00013198`) не отправляется вовсе, поэтому цепочка `ECNS` бездействует.

Правка, без сборки чего-либо:

```
fdtput <dtb> /remoteproc-adsp/glink-edge/apr/apr-service@9/dais qcom,cvd-v2.3
```

После этого эхоподавление и подавление стационарного шума работают.

**Дефект шкалы громкости разговора.** В профиле UCM громкостью назначен элемент
`RX0 Digital Volume` со шкалой от минус 84 до плюс 40 дБ. Верхняя треть ползунка
даёт положительное цифровое усиление и обрезает сигнал, а обрезание нелинейно и
потому разрушает линейную модель эхоподавителя: эхо возвращается. Безопасный
потолок это значение 84, то есть ровно 0 дБ.

## Что не решено

Двухмикрофонная обработка `DM_FLUENCE` и вторая версия эхоподавления
`SM_ECNS_V2` не собираются: процессор отвечает `ADSP_EFAILED` на
`TOPOLOGY_COMMIT`. Объявление двух каналов микрофона реализовано (см. `kernel/`)
и процессором принимается, но этого недостаточно. Нужна загрузка заводской
калибровки, а в драйвере нет ни поддержки разделяемой памяти, ни команд
регистрации калибровки.

## Состав

| Каталог | Содержимое |
|---|---|
| `reports/` | отчёты для ALT Bugzilla и для апстрима |
| `scripts/` | скрипты, выполняемые на телефоне |
| `kernel/` | патчи к драйверу и исходник до правки |
| `tools/` | разборщик файлов калибровки ACDB |
| `images/` | загрузочные образы, в репозиторий не входят |
| `acdb/` | заводская калибровка с устройства, в репозиторий не входит |
