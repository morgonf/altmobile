# Тема ALT для Plasma Mobile

Собрана 27.09.2026 по брендбуку Базальт СПО 3.8.1 и медиакиту
(www.basealt.ru/mediakit). Применение: `apply-alt-theme.sh` от пользователя в
сеансе, шрифт задаёт `../plasma-look.sh`.

- Цвета `ALTMobile.colors`: из Breeze Light, акцент #f5911f («Альт
  Мобильный», с. 7, 24), текст графит #333333, фон окон #f6f6f6, серые
  нейтральные. Ссылки #c46200: синий брендбук запрещает (с. 8), а #f5911f на
  белом даёт контраст 2.4:1. Текст на выделении графитом.
  `accentColorFromWallpaper` выключен, иначе Plasma возвращает цвета Breeze.
- Значки `icons/ALT`: наследует Breeze, `start-here-kde*` заменены знаком
  «Альт Мобильный» (гекс с вырезанной рамкой телефона). Взят `mono_icon.png`
  из медиакита, прозрачная область внутри скруглённого квадрата,
  векторизован potrace. Значок в `class="ColorScheme-Text"`, перекрашивается.
  Брендбук (с. 13) разрешает знак отдельно от надписи только по согласованию
  с маркетингом; здесь использована продуктовая иконка, а не знак base alt.
- Кнопка закрытия приложения в панели навигации: вместо крестика
  треугольник «назад» (`mobile-close-app` в той же теме значков), по
  просьбе пользователя. Кнопка рисуется на 4 пикселя меньше соседних,
  поэтому треугольник почти во всю рамку и с линией 1.7.
  Подменять `mobile.svgz` копией в `~/.local/share/plasma/desktoptheme/default/`
  нельзя: неполный каталог темы Plasma сбивает её цвета, и значки панелей
  становятся тёмными. Хватает темы значков.
- В `index.theme` обязателен `FollowsColorScheme=true`, иначе символьные
  значки не перекрашиваются и остаются графитовыми на тёмных обоях.
- Обои: `WP_1.jpg` из медиакита, CMYK в sRGB по встроенному профилю,
  вертикальный кадр 1080x2340.
- Шрифт PT Root UI (`fonts-ttf-PT-Root-UI`), брендовый Montserrat для
  интерфейса телефона слишком широк; статья TypeType не подошла, её шрифты
  коммерческие.

- Приложения GTK, в том числе Firefox, берут цвета из той же схемы через
  `kde-gtk-config` (пакет нужно поставить): тема GTK Breeze, цвета в
  `~/.config/gtk-3.0/colors.css`. До этого стояла Adwaita от Phosh, и
  Firefox был белым.

KWin держит тему значков и QML переключателя задач в памяти: после
применения нужен перезапуск сеанса.
