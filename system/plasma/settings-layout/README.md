# Группы «Настроек» ALT Mobile (01.10.2026)

Пользователь попросил переставить группы: настольные «Ввод и вывод»,
«Предпочтения пользователя», «Подключённые устройства» на телефоне
нелогичны. Модуль попадает в группу по полю
`X-KDE-System-Settings-Parent-Category`, вшитому в его `.so`, поэтому
раскладка задана файлом, а не пересборкой модулей. Патч
`packages/plasma-settings/plasma-settings-alt-layout.patch` читает
`/etc/xdg/plasma-settings-alt-layoutrc`:

- `[General] CategoriesDir` берёт группы из своего каталога
  (`/usr/share/alt-mobile/settings-categories`) вместо настольных;
- `[Modules] модуль=группа,порядок` переносит модуль, `hidden` скрывает.

Группы по образцу Android: Сеть и подключения, Экран, Звук и уведомления,
Оформление, Рабочий стол и управление, Приложения, Безопасность и учётные
записи, Батарея, Система. Скрыт `kcm_animations_x11` (вторая «Анимация»).
Новый модуль без строки в раскладке попадёт в группу из своих метаданных,
а если такой группы нет, не покажется: его надо дописать в раскладку.

Установка `install.sh` от root (группы, раскладка, пересобранный
`plasma-settings` с копией `.orig`).
