# NFC на OnePlus 6T (NXP PN553)

Проверено 01.10.2026. Чип NXP PN553 на i2c-3, адрес 0x28, драйвер ядра
`nxp-nci_i2c`, устройство `nfc0`. neard 0.20 (пакет ALT) запускает udev
(`99-neard.rules`), адаптер `/org/neard/nfc0`. Протоколы Felica, MIFARE
(Type 2), Jewel, ISO-DEP, NFC-DEP. ISO15693 (Type 5) нет. Пользователь
сеанса управляет neard без root (`at_console`).

`install.sh` от root:

- `org.neard-alt-mobile.conf` разрешает neard вызывать NDEF- и
  Handover-агентов программ пользователя. В пакете ALT правила для root
  ограничены `send_destination="org.neard"` (патч openSUSE), и агенты не
  получали бы меток;
- `/etc/neard/main.conf` с `DefaultPowered=true`, без него после загрузки
  адаптер выключен. `ConstantPoll=false`: neard с ним перезапускал опрос
  сразу, и карта в чехле находилась каждые 4 секунды;
- служба пользователя `alt-nfc-poll` держит опрос включённым. neard не
  возобновляет опрос после ошибки чтения («Error while reading NFC bytes»
  на метке без NDEF) и сам не запускает первый. Если опрос встал быстрее
  10 секунд после запуска (карта лежит у телефона), пауза удваивается до
  30 секунд.

- зависание контроллера. На одной из карт (Type 2, UID
  `05:8F:FE:34:F2:03:00`, чип Infineon) neard пишет «Could not connect», и
  PN553 перестаёт отвечать (I2C -121, таймауты NCI, включение адаптера
  -110). Выгрузка модуля не помогает, перепривязка к драйверу помогает.
  `alt-nfc-poll` сначала выключает и включает адаптер, а если чип молчит,
  запускает `alt-nfc-reset.service` (перепривязка от root). Запуск только
  этой службы пользователю сеанса разрешает `50-alt-mobile-nfc.rules`.
  Восстановление проверено, около 5 секунд.

Проверено 01.10.2026: метка Type 2 (MIFARE Ultralight, 7-байтный UID
производителя 0x34 «Микрон») читается, тип, протокол и UID приходят в
neard. Карт ISO-DEP (банковских) пока не видели.

Чего нет в стеке ядро NCI + neard: эмуляции карты (HCE), доступа к
secure element (оплата невозможна), произвольного обмена APDU через
neard, MIFARE Classic с ключами. Подробнее в `docs/settings-plan.md`.
