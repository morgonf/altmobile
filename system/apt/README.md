# Запрет обновления подменённых пакетов

`90-altmobile-hold.conf` кладётся в `/etc/apt/apt.conf.d/` скриптом
`install.sh` от root. В `RPM::Hold` перечислены пакеты, файлы которых
подменены нашими сборками (копии `.orig`, список даёт
`scripts/overlay-owners.sh`), свои пересборки (neard, plasma-settings,
libxslt) и ядро. Наши модули sa3103, imx37x и NFC лежат в `updates/`
текущего ядра, с новым ядром камеры и NFC не будет.

Это временная мера до своих RPM (пункт 2.7 плана
`docs/phosh-exit-and-tuning.md`). Удерживаемые пакеты тянут за собой
зависимые, поэтому при выходе новой версии KDE в Sisyphus часть пакетов
Plasma тоже останется на месте.

Проверено 03.10.2026 через `apt-get -s dist-upgrade`. Из 89 обновлений
ни одно не касается удерживаемых пакетов. Моделирование при этом
кончается ошибкой из-за перехода libmjpegtools 2.1 → 2.2 в Sisyphus, к
удержанию она не относится.

Осторожно. Среди обновлений есть `grub-efi`, `grub-common` и
`startup-config-qualcomm`. Телефон грузится через U-Boot
(`docs/boot-order.md`), обновлять их без проверки того, что делают их
скрипты установки, не стоит.

## Удержание всего локального репозитория (11.10.2026)

`scripts/local-repo.sh` пишет `/etc/apt/apt.conf.d/91-altmobile-repo-hold.conf`
со всеми пакетами локального репозитория. В `90-altmobile-hold.conf` были
только основные пакеты, а неудержанный подпакет (`-common`, библиотека) при
обновлении Sisyphus тянет удержанный основной по строгой зависимости: так
`dist-upgrade` заменял наши kaccounts и spacebar. На второй телефон файл
переносится вместе с репозиторием.

На первом телефоне моделирование `dist-upgrade` по-прежнему кончается
ошибкой перехода libmjpegtools 2.1 → 2.2 (см. выше), на втором проходит.
